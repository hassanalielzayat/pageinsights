# أداة التشخيص الاستراتيجي لصفحات فيسبوك — حسن علي (Hassan Ali)

حزمة ملفات جاهزة للنشر المباشر على **GitHub Pages** أو استضافة موقعك الشخصي (`hassanalielzayat.site` / `hassanalielzayat.github.io/portfolio/`).

## محتويات الحزمة

1. **`index.html`**: الصفحة الرئيسية للأداة (مرتبطة بملفات التصميم والبرمجة ومهيأة لمحركات البحث SEO ومعاينة الروابط OpenGraph).
2. **`assets/css/style.css`**: ملف التنسيق والهوية البصرية (الألوان والخطوط `Alexandria` و `DM Sans` وتنسيقات الطباعة والـ PDF).
3. **`assets/js/app.js`**: الكود البرمجي الكامل للأسئلة الـ 15، محرك حساب النتيجة، تخصيص الـ Call To Action، وتوليد ملف الـ PDF.
4. **`facebook_page_audit_standalone.html`**: نسخة مدمجة في ملف HTML واحد فقط (في حال رغبت برفع ملف واحد مستقل دون مجلدات فرعية).

## طرق النشر السريع

### الطريقة الأولى: النشر داخل مستودع البورتفوليو الحالي على GitHub Pages
إذا كنت ترغب أن يكون الرابط مثلاً: `https://hassanalielzayat.github.io/portfolio/audit/`
1. أنشئ مجلداً جديداً باسم `audit` داخل مستودع `portfolio` على GitHub.
2. ارفع بداخله ملف `index.html` ومجلد `assets/`.
3. سيصبح الرابط متاحاً فوراً للعملاء على: `https://hassanalielzayat.github.io/portfolio/audit/`.

### الطريقة الثانية: النشر كمستودع مستقل أو نطاق فرعي (Subdomain)
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `fb-audit`) وارفع داخله `index.html` ومجلد `assets/`.
2. من إعدادات المستودع **Settings → Pages** فعّل النشر من الفرع الرئيسي `main`.
